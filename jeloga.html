The Challenge

Build Uber for Nigeria. From Nothing.

Mr. Okezie came to me with a clear brief: build a full ride-sharing platform for Nigeria — from zero. No existing codebase, no design files. Just a vision: an Uber-like experience built for the Nigerian market, fast.

The scope was ambitious: a rider mobile app, a separate driver app, a web-based admin dashboard for operations, a live backend to handle real-time bookings and payments — all deployed, all integrated, all production-ready.

Most platforms like this take large teams 6–12 months. We did it in under 3, and Jeloga went live on both the App Store and Google Play Store handling real user bookings from day one.

Architecture

Three Layers, One Platform

📱 01 ──

Mobile App

Two separate React Native apps — one for riders, one for drivers — sharing a single codebase and deployed to both iOS and Android simultaneously.

  • Rider app: Book, track & pay in-app
  • Driver app: Accept rides, navigation, earnings
  • Live location tracking on map
  • Push notifications for all booking events
  • App Store & Play Store submission
💻 02 ──

Web Dashboard

A Next.js admin panel giving the Jeloga operations team complete visibility over the platform — fleet, bookings, drivers, and revenue — from any browser.

  • Live fleet map with driver positions
  • Booking management & history
  • Driver onboarding & verification
  • Revenue reports & earnings breakdown
  • User management
⚙️ 03 ──

Backend & APIs

A Node.js REST API handling all the real-time logic — ride matching, location updates, payment processing, and notifications — built to scale as the user base grows.

  • Ride matching & dispatch logic
  • Firebase real-time location sync
  • Paystack payment integration
  • Driver-rider rating system
  • Deployed & monitored in production

Features Built

Everything a Ride-Sharing Platform Needs

📍

Real-Time Tracking

Live driver location updates on an interactive map — riders see exactly where their driver is, updated every second.

💳

In-App Payments

Paystack integration lets riders pay fully in-app. Drivers see their earnings instantly after each completed ride.

🔔

Push Notifications

Booking requests, driver arrivals, ride completions — every event triggers the right notification at the right moment.

⭐

Rating System

Riders rate drivers and drivers rate riders after every trip — building platform trust and accountability over time.

🛡️

Driver Verification

Drivers go through an approval workflow with document upload and admin review before accepting rides on the platform.

📊

Admin Dashboard

Full operations control: live fleet view, trip history, driver management, revenue reports — all in a clean web interface.
